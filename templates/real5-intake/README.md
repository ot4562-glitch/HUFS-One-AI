# HUFS One AI | 팀원 5명 입력 안내 (확정)

**Google Forms는 사용자가 이미 구성했다.** 인적사항·제1전공·이중전공·취득/수강 중 총학점(본인 확인용)·관심사·방학/학기 중 활동·목적별 동의를 **Google Forms 응답 CSV 그대로** 받는다. 중간 변환용 `students.csv`나 별도의 CSV 템플릿은 만들지 않는다.

## 실제 입력 파일 두 종류

1. **Google Forms 응답 CSV:** Google Forms에서 내보낸 원본 파일을 그대로 사용한다. 현재 이 폴더에 사용자 제공 **응답 예시 1건**이 있으며, 첫 행은 타임스탬프를 포함한 **26열**이다. 이 예시는 수강과목 CSV가 아니다. 제품의 데이터 입력 계약을 검토하는 데만 사용하고 개인 응답을 공개하지 않는다. 나머지 네 명의 응답은 아이디어가 채택되면 제공될 예정이다.
2. **학생별 수강과목 CSV:** [짧은 전사 프롬프트](SCREENSHOT_TO_CSV_PROMPT.md)를 복사하여 본인이 캡처한 이수과목 화면을 AI 또는 직접 작성으로 정리한다. **파일명만으로 학생을 구별**하고 CSV 안에 이름/ID를 반복하지 않는다.

각 학생별 수강과목 파일의 첫 행:

```csv
학기,학수번호,과목명,학점,이수구분,이수상태
```

**값의 뜻:** `학기`는 화면의 학기(예: `2025-1`), `학수번호`는 화면에 있으면 적고 없으면 빈칸, `과목명`과 `학점`은 원문 그대로, `이수구분`은 화면의 분류를 그대로 적거나 빈칸, `이수상태`는 `이수완료` 또는 `수강중`이다. **미래 계획 과목은 이 파일에 넣지 않는다.** 계획은 제품의 별도 학기계획 원장에서 관리한다. 과목이 같은 이름이어도 서로 다른 학기 수강 행은 그대로 남긴다.

**파일 이름:** `<Google Forms의 표시이름>.csv`. 앱 가져오기 과정에서 파일명(확장자 제거)을 Google Forms의 **표시이름 응답값**과 정확히 대응시킨다. 동명이인·중복 응답·일치하지 않는 이름은 자동으로 다른 학생에게 배정하지 않고 검수한다. 내부 계정ID/기록ID는 가져오기 코드가 생성한다.

## 구현 시 에이전트의 처리 순서

1. Google Forms 응답 CSV의 헤더는 **실제 제공된 내보내기 파일**을 기준으로 읽고, 질문 문구를 학적·전공·관심·동의 등 내부 필드로 매핑한다. 양식의 열 순서가 바뀌어도 명칭으로 연결한다. 알 수 없는 질문은 임의 해석하지 않는다.
2. 해당 이름의 과목 CSV를 연결한다. UTF-8/UTF-8 BOM 및 표준 CSV 따옴표 규칙을 지원한다. 행마다 학기·과목명·학점·이수상태를 검증하고 학수번호/이수구분이 비어 있으면 필요 여부를 판정해 검수 대상으로 남긴다.
3. 학생이 캡처와 과목 행을 대조한 뒤, 학업규칙 에이전트가 적용 학번·전공별 **공식 한국외대 졸업요건**으로 계산한다. 중복인정·대체·재수강·비학점 졸업요건은 **내부 규칙/검수 기록**으로 관리하며 학생에게 추가 CSV 제작을 요구하지 않는다.
4. 실제 5명 각각의 `FORM_RECEIVED / COURSES_RECEIVED / STUDENT_REVIEWED / RULE_MATCHED / INDEPENDENTLY_VERIFIED / DEMO_READY`를 별도로 점검한다. 지금은 예시 응답 1건만 확인했으며 **수강과목 CSV·5명 완성팩은 아직 확인되지 않았다**.
5. 이 두 입력을 한 번 가져온 후에는 실제 변경된 기록만 업데이트하고, 기존 이수내역/검증·동의 기록은 보존한다.

## 개인정보와 공개 경계

이 폴더의 사용자 응답 예시에는 개인정보가 있을 수 있다. **`.gitignore`와 `.dockerignore`에서 이 폴더의 `*.csv` 전부를 제외**하도록 했다. 폴더에 남은 사용자 예시 파일은 삭제·재작성하지 않았다. 실학생 캡처·추가 응답·계산 결과는 가능하면 `local_only/real5/`에서 보관하고, 공개 GitHub·CI·정적 번들·PDF에 포함하지 않는다. Google Forms에서 응답을 수집하는 것과 CLOVA AI·NCP·발표의 사용동의는 각각 확인한다.

실제 문항은 이미 구성된 Google Forms의 응답 CSV 헤더를 기준으로 확인한다. **별도 질문지 MD·새 폼·빈 CSV 템플릿 배포는 필요하지 않다.**
