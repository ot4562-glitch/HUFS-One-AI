# HUFS One AI — 참고 HUFSAbility 정보구조와 현재 UI 대응

**목적:** 기존 HUFSAbility의 **공개 메뉴와 사용자 계정에서 관찰된 화면 계층을 참고**하여 HUFS One AI만의 독립적인 제품 UI를 설계하고, 현재 코드/권한/미지원 범위를 정직하게 비교한다. 과거 학생 화면의 이미지·DOM/CSS/JS·세션·개인 기록/학교 로고를 리포지토리에 복사하거나 그대로 복제하지 않는다.

## 참고 범위의 차이

| 참조 소스 | 알려진 범위 | 현재 제품에서의 취급 |
| --- | --- | --- |
| 학교 공개 UI/학생안내 | **5분류/24개 학생 기능**, 비로그인 **4영역** | 메뉴 명칭·정보 위계 참고. `/menu` 및 HUFSAbility disclosure에서 **모두 미지원** 배지, 공개 4영역은 공식 첫 화면 링크만 |
| 학생 계정 관찰 | **11개 영역·76개의 화면 구조**를 관찰한 UI 조사 | 학교 운영 UI가 현재 동일하다는 실시간 보증 아님. 원본 레이아웃/문구/상호작용·로고/학생 내용을 제품 자산으로 사용 금지 |
| HUFS One AI React | **상단 독립 주요 메뉴 8개**, 모바일 하단 **5탭**, 배너·요약 카드/경험·보관함·학업·시연 | 실제 코드/합성 브라우저 사용 가능 범위를 표시, 실 Google/학교 자료·접근성 인수 미완료 |

## 공개 학생 메뉴 5분류 · 24기능

| 분류 | 기능 수 | 대표 정보(메뉴 명칭 참고, 본 제품 미지원) |
| --- | ---: | --- |
| 역량관리 | 4 | 핵심역량 소개·점수·진단·적응 검사 |
| 교과/비교과 | 5 | 이수 교과·비교과 프로그램·외부활동·학습 공동체·장학 신청 |
| 채용 | 6 | 교내/워크넷 채용·멘토링·직업 탐색·청년인턴/강소기업·외대친화기업 |
| 경력개발 | 4 | 진로 목표·로드맵·포트폴리오·진로/취업 도서 |
| 통합상담 | 5 | 지도교수·진로취업·심리·외국인 유학생·학습 상담 |

비로그인 4영역은 **교내 비교과·장학공지·공지사항·채용정보**를 공식 사이트로 이동시키는 참조 링크이다. 학교 실제 세부 기능·데이터를 본 웹에 통합했다는 의미가 아니다.

## 학생 계정 관찰의 11개 영역

역량관리·교과/비교과·채용/고용24·현직자 멘토링·전공/진로설계·통합상담·커뮤니티·취업조사·교수지원(학생)·오픈배지·취업통계의 정보구조는 **당시 관찰 자료의 범위**이다. 현재 API·학교 접근권/모바일 동작/신청 성공을 검증한 목록이 아니다. 새 제품의 공식 기능이 아님.

**제품 구현 원칙:** 원본 학교 정보구조는 탐색 사용성 관점에서만 흡수하고, 원형 CSS·직접 URL·세션 코드·스크린샷/폰트·브랜드를 무단 복제하지 않는다. 독립 네이비/블루 토큰·제품 배너/사용자 행동 흐름과 미지원 표기를 유지.

## 현재 HUFS One AI 화면

`/` 오늘의 요약(맞춤 공고/확정 7일 내 마감/취득 학점) · `/opportunities` 기회 · `/notices` 학사공지 · `/graduation` 학업/What-if · `/experience` 경험 · `/saved` 보관함 · `/applications` 지원 초안 · `/clubs` 가상 동아리, `/menu` 전체 메뉴. 상단 8개는 독립 제품 기능이며 5개 모바일 탭은 오늘·기회·경험·졸업·보관함이다.

학업/추천의 숫자는 현재 검증된 actor/grant/RulePack/asOf/source만. `NOT_SHARED`, `UNKNOWN`, `PENDING`일 때 0·가능/합격으로 위조하지 않는다. 공고·학사 원문/학교 원 UI가 불가능하면 학교 공식 첫 화면/출처로 안내하고 비지원 기능을 감추지 않는다.
