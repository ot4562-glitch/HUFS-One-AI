## 2. 추가 기능 생명주기: 심민성 구현 우선 → AI 구현 인계

**단계 A — 최초 구현(심민성).** 신규 기능 이슈를 `assignees=['ot4562-glitch']`로 만든다. 기존 자료와 현재 구조/PR을 읽고 **할 수 있는 범위까지 Core/Contracts/API/DB/인증·권한·비AI 화면 연계/순수 비즈니스 로직·통합/자동 테스트를 직접 구현**한다. 설계만 남기고 기계적으로 조기 이관하는 방식은 기준이 아니다.

**단계 B — 데이터 필요성 점검.** 공식 문서·학칙/공고·포스터·행사·멘토·상담기관·NCS·배지·학습 프로그램·취업통계·다국어 안내·이미지 게시권·독립 Gold가 필요한 경우 **새 `[데이터 요청][김채윤]` 이슈**를 만든다. `assignees=['qamarrchae']`, 기능 번호/필요 필드/공식 출처·판본·목적별 권리·Gold·UI asset·희망 인수 시점/상태를 적는다. **기능 이슈에도 김채윤을 공동 assignee 추가**한다. 이슈 쌍을 서로 연결한다. 현재 13개 기능의 공통 대규모 요청은 [#360](https://github.com/ot4562-glitch/HUFS-One-AI/issues/360)을 사용하고, **추가 기능·새 범위에 대해서는 새로운 별도 데이터 이슈를 생성**한다. 같은 범위/원장 이중 요청 여부를 확인한다.

**단계 C — AI 코드 충돌/겹침을 발견하면 즉시 인계.** AI 범위에는 **HCX-007·CLOVA OCR·RAG·NLP·문서/의미 추출, 규칙·가중치·스코어·랭킹·Jaccard/BM25/TF-IDF·임베딩·ML·예측/개인화 추천, AI 정확도/비교 실험**이 포함된다. LLM을 호출하지 않는 **코드 기반 AI도 동일하게 AI 작업**이다. 이 부분의 실개발 주담당은 **박준영 또는 이의상 중 한 명**으로 지정한다. 주로 추천·랭킹·예측/정량 QA는 박준영, OCR/NLP/RAG/문서/다국어 처리 등은 이의상이 자연스러운 출발점이지만 **두 사람은 두 기술 영역을 모두 개발할 수 있고 작업량·기존 담당/코드 소유에 따라 자유롭게 조정**한다. 상대방은 필수 교차 리뷰/피드백에 참여한다.

**단계 D — 담당자 기록.**
- AI 기능 단계 진입 후: `assignees=[선정한 AI 주담당]` + (데이터 필요 시 `'qamarrchae'`). 심민성은 기능 코어의 **비AI 인프라/계약·보안/통합 코드 구현과 상시 리뷰**를 계속 수행할 수 있으며, 이 진행은 이슈 댓글/PR에 남긴다.
- AI 코드가 없어 끝까지 일반 기능인 경우: `assignees=['ot4562-glitch']` + (데이터 필요 시 `'qamarrchae'`). 개인별 고정 역할 이슈와 분리한다.
- 데이터 요청: `assignees=['qamarrchae']`, 신규 기능 번호와 인수 항목 연결. 웹 디자인은 이서연이 UI 서브작업/PR을 인수한다.
- AI QA는 **박준영**, 사용자 관점 가벼운 전 과정 시연·제보는 **김채윤**, 웹 디자인·기능 연결은 **이서연**, 코드와 품질의 상시 통합 검수는 **심민성**이다.

**단계 E — 완료 판단.** 이슈의 실제 PR SHA·CURRENT HEAD CI·비작성자 코드 리뷰·실데이터/권리·독립 Gold·HCX/OCR 시험·UI 실제 배치·사용자 시연/기술 QA·실운영 영수증을 **각기 다른 증거**로 기재한다. PR Open/합성 PASS는 실서비스 완료가 아니다.

## 4. 절대 유지할 안전 경계

- `csv/`의 기존 **Google Forms 1개 + 개인별 수강 CSV 4개**는 보존하고 임의 삭제·수정·재인코딩·이동·공개 웹/운영 이미지 포함을 방지한다. 비밀·실명/SID·학생 원본 자료를 새 공개 이슈/PR에 담지 않는다.
- 자료·포스터의 읽기/게시/OCR/HCX-007 전송·보존·철회 권리는 목적별로 확인한다. 합성 fixture는 독립 사람 Gold가 아니다.
- 실 인증·현재 동의/actor·RLS/CSRF·권리 철회·자료 시점과 sourceRevision을 검증하며 학교 자격/발급·개인 취업 예측은 공식 인증으로 둔갑시키지 않는다.
- 테스트 미실시 `NOT_RUN`, 운영 미연결 `NOT_CONNECTED`, 설정 미완 `CONFIGURATION_REQUIRED`, 출시 미인수 `RELEASE_BLOCKED`를 유지한다.
