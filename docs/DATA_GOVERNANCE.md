# Private 저장소의 명시 승인 학생 수강 CSV 예외

기존 두 학생 수강과목 CSV는 PR #1에서 별도 요청에 따라 Private 저장소에 포함했다(48행과 39행). **2026-10-30 사용자의 추가 명시 지시로 `csv/이수과목_이의상.csv` 28행을 별도 PR에 추가**한다. 세 파일은 동일한 6열 헤더를 사용한다. 신규 파일은 데이터 내용을 바꾸지 않고 BOM 없는 UTF-8로 변환했다. 업로드된 원본을 수정하지 않는다. 이 요청은 다른 학생 파일 전체에 대한 허가가 아니다.

**주의:** 파일명 자체에 표시이름이 포함된다. 비공개 브랜치라도 초대된 협업자가 열람/복제할 수 있다. 다른 학생의 저장·팀 공유 동의 여부는 업로드 지시와 별개로 확인할 필요가 있다.

- 개별 허용된 세 파일 외 다른 CSV·Google Forms 원본·학번·성적·사진·캡처·키는 GitHub로 옮기지 않는다.
- 이번 파일 한 건의 승인으로 다른 CSV 업로드, 전체 팀원의 원장 공유권한, CLOVA 전송, NCP 저장·발표 공개까지 허용되는 것은 아니다.
- `.gitignore`는 **지정된 세 CSV만 예외**로 두고 나머지는 기본 차단한다. `.dockerignore`는 **csv 폴더 전체를 배포 이미지에서 제외**한다.
- 브라우저 정적 파일, public 폴더, 합성 fixture, CI 출력, 이슈/PR 본문, AI 프롬프트·로그에 실제 과목 데이터를 넣지 않는다.
- 공유 가능한 개인별 요약은 Architecture.md A02 SharingGrant와 별도 동의를 거쳐 생성한다.
- 향후 저장소를 공개하려면 파일 삭제만으로 과거 커밋·clone의 개인정보가 지워지지 않으므로 이력 처리·당사자 동의를 검토해야 한다.

세 CSV의 형식 확인은 **공식 졸업 학점 판정이나 학생별 팀 공유 동의 검증** 완료를 뜻하지 않는다.

## 4인 제출·동의 검증 게이트 (2026-10-30 확정)

- **개발자 5명 ≠ 개인자료 제공자 5명.** 이번 자료 수집 목표는 **김채윤·이의상·심민성·이서연 4명**의 수강 CSV 각1개(6열)와 같은 4명이 응답한 Google Forms **통합 CSV 한 개(원문 26열)**다. **박준영은 CSV/Forms 제출 대상이 아니다.** 이서연의 Forms 응답은 아직 미제출이고 나머지 제출현황은 실제 파일 검증 전에는 완료로 인정하지 않는다.
- 지금 GitHub `csv/`에 파일 3개가 있어도 그중 두 개만 이번 명단의 이름과 직접 대응한다: `이수과목_심민성.csv`, `이수과목_이의상.csv`. `이수과목_까마르.csv`는 사용자·alias·이용 동의 대응이 확인될 때까지 **4명 중 누구에게도 자동 연결/DB import/시연 표시 금지**. 보관 결정과 당사자 접근권을 별도로 검토하고 임의로 삭제·재배정하지 않는다.
- **실제 파일/폼 검증은 제한된 로컬 경로에서만**: Forms 헤더 26개(중복·변경·별칭 충돌), 명단 4명/중복 응답/표시이름 대응, 6열 과목 헤더·UTF-8(BOM 허용)·CSV 인용·학점·상태, EARNED/IN_PROGRESS 분리, 자기보고 총학점과 원장의 불일치, 학점 중복/재수강·학번별 규칙·근거, 원본 hash와 import 버전을 확인한다. 누락/불명확하면 `PENDING` 또는 `NEEDS_REVIEW`와 비식별 이슈 코드만 남긴다.
- **동의는 목적별**: 팀 정제 검토, 실제 shared DemoProjection/SharingGrant의 섹션·만료·철회, 비공개 NCP 저장, 외부 CLOVA 전달, 발표·녹화·표시이름은 각각 다르다. Forms의 팀 검토 동의만으로 원본 전체를 모든 팀원에게 공개하지 않는다. GitHub Private이라는 사실도 개인별 열람 동의가 아니다.
- 5개 `S01`~`S05` 시연 슬롯은 유지하되 실제 입력자는 최대4명이며 남는 슬롯은 `PENDING` 또는 명확한 `SYNTHETIC`이다. 실제 표시이름·파일명의 이름↔가명 ID 매핑은 제한된 별도 보관소에만 둔다. 무단 공유·개인정보 역추적을 막기 위해 GitHub/CI/로그/이슈/외부 AI에는 실제 4인 Forms 응답, 이수행, 신원 매핑·성적/학번을 넣지 않는다.
- **새 파일 업로드는 별도 명시 승인**이 필요하다. 기존 3개 CSV의 비공개 업로드 예외는 미래 4인 통합 Forms 또는 김채윤·이서연 CSV의 GitHub 게시 권한까지 확장하지 않는다.

**검증 보고 형식:** 사람 이름/원문 대신 파일 수, 26/6열 여부, 행수, 익명 이슈 수, 각 consent 목적별 `VERIFIED|PENDING|DENIED|REVOKED`, 해시·버전, 수기 대조/독립 검토 여부만 남긴다. 동의가 없거나 데이터가 부족한 학생을 완성 상태로 표시하지 않는다.
