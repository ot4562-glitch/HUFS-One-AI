# Private 저장소의 명시 승인 학생 수강 CSV 예외

기존 두 학생 수강과목 CSV는 PR #1에서 별도 요청에 따라 Private 저장소에 포함했다(48행과 39행). **2026-10-30 사용자의 추가 명시 지시로 `csv/이수과목_이의상.csv` 28행을 별도 PR에 추가**한다. 세 파일은 동일한 6열 헤더를 사용한다. 신규 파일은 데이터 내용을 바꾸지 않고 BOM 없는 UTF-8로 변환했다. 업로드된 원본을 수정하지 않는다. 이 요청은 다른 학생 파일 전체에 대한 허가가 아니다.

**주의:** 파일명 자체에 표시이름이 포함된다. 비공개 브랜치라도 초대된 협업자가 열람/복제할 수 있다. 다른 학생의 저장·팀 공유 동의 여부는 업로드 지시와 별개로 확인할 필요가 있다.

- 개별 허용된 세 파일 외 다른 CSV·Google Forms 원본·학번·성적·사진·캡처·키는 GitHub로 옮기지 않는다.
- 이번 파일 한 건의 승인으로 다른 CSV 업로드, 전체 팀원의 원장 공유권한, CLOVA 전송, NCP 저장·발표 공개까지 허용되는 것은 아니다.
- `.gitignore`는 **지정된 세 CSV만 예외**로 두고 나머지는 기본 차단한다. `.dockerignore`는 **csv 폴더 전체를 배포 이미지에서 제외**한다.
- 브라우저 정적 파일, public 폴더, 합성 fixture, CI 출력, 이슈/PR 본문, AI 프롬프트·로그에 실제 과목 데이터를 넣지 않는다.
- 공유 가능한 개인별 요약은 Architecture.md A02 SharingGrant와 별도 동의를 거쳐 생성한다.
- 향후 저장소를 공개하려면 파일 삭제만으로 과거 커밋·clone의 개인정보가 지워지지 않으므로 이력 처리·당사자 동의를 검토해야 한다.

세 CSV의 형식 확인은 **공식 졸업 학점 판정이나 학생별 팀 공유 동의 검증** 완료를 뜻하지 않는다.
