# Private 저장소의 두 학생 과목 CSV에 한한 예외

사용자는 **csv/에 놓인 기존 두 명의 과목 CSV를 Private GitHub PR에 올리도록 명시**했다. 각각 48행과 39행, 헤더는 6열이다. 한 로컬 원본은 CP949였으며 GitHub에서는 한국어 문자를 보존해 UTF-8로 업로드한다. **로컬 원본은 변경하지 않는다.**

**주의:** 파일명 자체에 표시이름이 포함된다. 비공개 브랜치라도 초대된 협업자가 열람/복제할 수 있다. 다른 학생의 저장·팀 공유 동의 여부는 업로드 지시와 별개로 확인할 필요가 있다.

- 허용된 두 파일 외 Google Forms 응답 원본·학번·성적·사진·캡처·키 등은 GitHub로 옮기지 않는다.
- 이번 예외는 새 CSV 전체 업로드, 실제 다섯 명의 원장 공유권한, CLOVA 전송, NCP 저장/발표 공개까지 허용한 것이 아니다.
- .gitignore는 **지정한 두 CSV만 예외**로 두고 새 CSV는 기본 차단한다. .dockerignore는 **csv 폴더 전체를 배포 이미지에서 제외**한다.
- 브라우저 정적 파일, public 폴더, 합성 fixture, CI 출력, 이슈/PR 본문, AI 프롬프트·로그에 실제 과목 데이터를 넣지 않는다.
- 공유 가능한 개인별 요약은 Architecture.md A02 SharingGrant와 별도 동의를 거쳐 생성한다.
- 향후 저장소를 공개하려면 파일 삭제만으로 과거 커밋·clone의 개인정보가 지워지지 않으므로 이력 처리·당사자 동의를 검토해야 한다.

두 CSV가 존재한다는 것은 **입력 파일의 형식 검증** 사실이지 공식 졸업 학점 판정과 공유 동의 검증이 완료됐다는 뜻이 아니다.
