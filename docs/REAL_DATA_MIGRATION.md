## 범위: 데이터 수요가 생기면 출처를 확장한다

장학·수업·학사일정·대외활동 외에 학칙/전공/학번별 졸업요건, 강의/시간표/강의계획서, 등록금·기숙사·복지, 국제교류/유학생, 비교과/학생회·동아리/행사, 취업·인턴/창업, 상담·튜터링/멘토링, 외부 프로그램·NCS/배지·통계, 학내 기관/시설, 서식·FAQ 등 **제품의 모든 현재 및 신규 기능 데이터 의존성**을 발굴한다. 웹 메뉴가 없는 영역도 서비스 기능이 요구하면 범위에 포함한다. 공식 HUFS 도메인에서 찾지 못한 교외 정보는 해당 기관의 공개 소스/허용된 API 등 별도 출처를 검토한다.

기계 판독형 출발점: [tools/real-data/source-seeds.json](../tools/real-data/source-seeds.json).
- 파일의 공식 URL은 공개 검색으로 확인한 **발견용 시작점**이며 데이터 수집 성공·권리 승인·전체 사이트 커버리지를 뜻하지 않는다.
- `DISCOVERY_SEED_ONLY`: 시작 URL만 있음. 실제 내용/출처 판본은 0건.
- `SOURCE_GAP`: 해당 기능에 필요한 공식·교외 출처 미발견/미매핑. 다음 탐색에서 채울 대상.
- `PRIVATE_INTAKE_REQUIRED`: 실제 학생 본인 자료(학업/성적/경험/지원)는 공개 웹 크롤러가 아닌 인증된 본인 입력·동의 경로에서만 채움.

## 수집기→신뢰된 실데이터로 전환되는 단계

`SOURCE_SEED → URL_DISCOVERED → ACQUISITION_PENDING/REVIEW → FETCHED_RAW → EXTRACTED_CANDIDATE → NORMALIZED_DRAFT → SOURCE_REVIEWED → APPROVED_FOR_PURPOSE → DB_PROJECTION → LIVE_API → LIVE_UI`

1. **Discovery:** 도메인/부서/학과 및 외부기관 사이트맵·RSS·링크·이전 게시판 페이지와 첨부파일을 발견. 사이트/부하·robots·계정 권한을 매번 구분. URL만 찾았으면 `FETCHED_RAW`로 승격 금지.
2. **Acquisition:** 일반 공개 자료는 약관·공개성·사이트별 접근 조건과 수집 정책을 확인한 HTTP/브라우저 경로로 취득. robots Disallow는 존재 여부가 아니라 취득 방법의 검토 신호이며 401/403·CAPTCHA·인증·권한을 우회하지 않는다. 학생 공통자료는 정당한 학생 접근권·수집/공개 범위가 있어야 한다.
3. **Parsing:** HTML, PDF, HWP/HWPX, 이미지/표의 날짜·지원 조건·전공·학번·캠퍼스·장소·분반·학수번호·프로그램 분류를 구조화. 한 게시물의 서로 다른 연도/학기/조항을 섞지 않는다.
4. **Provenance:** 원문 URL·원본 SHA-256·발행/수정/수집/사람 검증 시각·원문 증거 문단·bbox·출처/판본/취소/삭제·이용목적과 만료를 `SourceRevision` 및 기존 데이터 계약에 연결한다.
5. **Consumer:** 현재 UI/API의 합성/fixture 의존성을 기능별로 인벤토리화하고 검증된 `REAL_APPROVED` 자료를 실제 DB 및 API에 연결. 실제 데이터가 없으면 `NOT_CONNECTED`/빈 상태/UNKNOWN을 반환하며 개발용 가상 자료로 조용히 대체하지 않는다.
6. **Freshness:** 신규/정정/취소/삭제·권리철회 및 유효기간 만료 시 원본, 검색/RAG 캐시와 사용자별 추천을 무효화. 단기 게시물/마감과 장기 규정의 점검 주기를 구분한다.

## 기능별 마이그레이션과 허용 상태

| 소비 기능 | 실원본 데이터 | 전환 검증 기준 |
| --- | --- | --- |
| 맞춤 공고/장학/비교과·진로 | 학교·교외 모집 공고, 대상·기간·원문, 공식 제출 링크 | 현재 시점·마감 변경/취소·조건 인용 및 중복 통합 |
| 학사공지·캘린더 | 공식 학사일정·학과/부서 공지·교과·신청일 | KST, 학년/캠퍼스, 개인 적용 가능성/불명 분리 |
| 학점·졸업·What-if·예측 | 학칙/학번별 규정/교과/과거 개설, 본인의 실제 학업 원장 | 공식 적용판·예외·학수번호/학기·빈도≠미개설; 공식 졸업 확정 주장 금지 |
| 교환·국제학생 | 국제교류/파트너별 자격, 국외교류학점, 다국어 안내 | 출처/시점·외국대학별 추가 요건·번역 검증 |
| 경험·멘토·배지/학습·상담 | 공개 프로그램 정보와 본인이 입력·동의한 경험/활동 | 공식 프로그램과 개인 기록/AI 추론 후보 구분 |
| 캠퍼스·시설/동아리/지원 | 공개 행사·학생회·동아리·기관·시설 및 복지 공지 | 조직/장소/학기 식별·중복·권리/이미지 검증 |
| 통계·NCS/취업 해설 | 이용 가능한 공개 통계/직무 표준/기관 발표 | 모집단·분모/연도/억제값·원문 정의·집계/해설 검증 |
| FAQ/RAG/검색 | 허용된 모든 공식 FAQ·규정·게시물·첨부파일 | 정확한 원문/판본·인용, 미확인 내용은 UNKNOWN |

**모든 기능 공통:** `datasetMode`와 provenance/출처 revision을 실제 응답에 일치시킨다. 합성 시연/테스트는 보존하되 운영 데이터가 없는 자리를 합성으로 숨기지 않는다. 새 실제 사용자 원본·비밀·자격증명은 공개 Git/Pages/CI에 넣지 않는다. 재게시/외부 모델 전송은 공개 웹 열람과 구분하여 사용 범위를 확인한다.

## 운영·측정 게이트

- 소스: 발굴 사이트/학과 수, 목록 대비 URL 발견률, robots/약관 검토 대기, 자료 재사용 가능 상태
- 수집: 목록/페이지네이션/첨부까지 실제 성공률·중복/중단 사유·갱신 지연, 외부 서비스 부하/429 처리
- 데이터: 필드/날짜·전공·학수번호 정답률, UNKNOWN 사유, 출처/증거 누락 0 목표, 취소/정정 재현
- 연결: 기능·화면별 `REAL` 사용 비율, 합성 fallback 0건, DB/API/UI 응답별 근거 추적, 사용자별 권한 검증
- 실제 운영: 각 단계 `NOT_RUN / FAIL / PASS` 별도 기록. 독립 자료·사용권·실계정/DB 인수 전 `RELEASE_BLOCKED` 유지.

`node tools/real-data/verify-seeds.mjs`는 **오프라인 소스 목록 검사만** 수행한다. 실제 HTTP 크롤러·자료 확보·출시 준비 검사와 구분한다.
