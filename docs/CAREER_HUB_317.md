## 구현된 BETA 경로

- `/career`: **본인 확인된 BETA**의 비공개 자기소개·경험/활동 분류와 기간·자기보고 타임라인, 본인 승인 주제 기반 설명형 탐색 로드맵. 합성 S01–S05/REVIEWER·익명에는 owner 포트를 만들지 않는다. 변경은 기존 버전 조건부(CAS) API를 사용한다.
- `/experience`: 경험 원문 → AI 후보(`NEEDS_REVIEW`) → 학생 명시 승인/철회 경로. 승인 후보는 학교의 공식 인증·취업 적격·숙련도를 증명하지 않는다.
- `/owner-opportunities/:id`: 허가된 본인 데이터의 기관 홈페이지(별도 HTTPS 필드), 원문 상태와 기존 규칙 설명을 분리한다. 실제 기관 링크는 제공·권리·현재 검증된 경우에만 표시한다.
- `/owner-ai`: 명시적 AI 실행과 수동 조회. `LIVE_PROVIDER_RUN` / `CACHED_PREVIOUS_RUN` / `SYNTHETIC`을 구분하며 관찰하지 않은 실비용·정확도·호출을 생성하지 않는다.
- #330: 커리어 응답 조회 전후에 본인 `personalStorage` 동의 및 판본을 재검사하고, 가상 경험·가상 북마크를 본인 전용 타임라인에서 제외한다. 계정 전체 조사로 오인하지 않도록 현재 페이지 분량을 표시한다.
