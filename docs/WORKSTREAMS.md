## 참여와 자료 범위

사용자 확인으로 **공모전 참여 5명 전원 동의와 HUFSAbility 자료 수집 허가가 확보**되어 있다. 개인 수강·Forms 원본 제공자는 **심민성·이의상·김채윤·이서연 4명**이며, 박준영의 학업 코어 담당과 구분한다. S01~S05, 빈 SYNTHETIC 계정, REVIEWER 데이터를 실제 4인 원본과 섞지 않는다.

공식 강의시간표 공개 교수명·강의명은 허가된 수업정보의 필요한 용도로 제한한다. 일괄 이름 마스킹을 새 필수 게이트로 추가하지 않는다. 원본별 필드·목적·보관·외부 AI 전송/재배포·철회와 과거 Git/clone 접근 검수는 [DATA_GOVERNANCE](DATA_GOVERNANCE.md), #46/#133에서 별도로 추적한다. #212 이후 현재 Git 보호 경로 제거와 과거 이력 정리는 서로 다른 증거다.

## 협업 안전·PR 검수

- 담당별 브랜치·worktree·포트·일회용 DB를 격리한다. 다른 세션의 미커밋 변경을 덮어쓰거나 기존 브랜치를 강제 갱신하지 않는다.
- 공통 Zod/TopicCode, SQL migration, lockfile, Actions, auth/scope는 기술 총괄과 소비자 검토 대상이다. 일반 병합 조건은 [PR_WORKFLOW](PR_WORKFLOW.md)를 따르며 자동 COMMENT와 독립 사람 APPROVED를 구분한다.
- 동일 actor/grant/asOf/epoch/version과 철회·401/403/409·늦은 응답에서 이전 학생 데이터가 보이지 않게 한다.
- 합성 CI, 일회용 실제 PostgreSQL 시험, 실제 운영, 사람 인수를 분리한다. 사용자 승인 범위를 넘는 유료 자원·공개 서비스 변경은 이번 유지관리의 완료 조건이 아니다.
- 고정 수락률은 복합 게이트의 증거율이며 개인 역량·제품 전체 완성률이 아니다.
