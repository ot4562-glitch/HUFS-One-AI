## 수집·관찰 한계

- 비로그인 공개 자료만 수집했다. 학생의 포털 계정·쿠키·성적·상담자료·수강내역·개인 대시보드를 읽지 않았다. 로컬 브라우저는 기존 사용자 프로필이 아닌 임시 독립 프로필을 사용했다.
- HTML 수집은 요청 사이 약 1.2초 간격을 두었다. 페이지네이션 전체 순회, 자동 반복 일정, 신청 폼 제출은 하지 않았다. 스크린샷은 별도 시각의 실제 공개 화면이므로 HTML 요청시각과 정확히 같지는 않다.
- `wis.hufs.ac.kr/robots.txt`의 `Disallow: /` 및 공식 사이트의 `/bbs/` 제한을 확인했다. 해당 원문은 로컬 크롤링하지 않았다. G11의 자동 수집기는 검토대기로 멈추었고 수동 정책 검토 결과는 수집 금지다. robots가 404인 공개 호스트도 재사용 허가가 있다는 뜻은 아니다.
- 화면 PNG는 지정한 뷰포트의 캡처이며 전체 스크롤 페이지라는 보장은 없다. H03은 주요 본문·일정까지 보이지만 하단 일부는 화면 밖이다. 포스터 내용의 직접 판독은 검토 문서에 따로 표시했다.
- G12 PDF는 원본 파일을 보관하고 공개 텍스트를 대조했다. 웹 PDF 이미지 렌더링은 도구 오류로 확인하지 못했다. 학점표의 시각적 검토는 같은 공식 규정의 HTML 화면 `screenshots/G01.png`로 수행했다. PDF 전체 표·부록을 시각 검수한 자료로 주장하지 않는다.
- HTML은 참조 이미지/CSS까지 모두 내려받은 완전한 오프라인 웹 아카이브가 아니다. 텍스트·원본 구조·현재 화면을 함께 사용한다. 첫 페이지 표본은 전체 공고나 전체 학생을 대표하지 않는다.
