# HUFSAbility — 현재 제품 참조용 공식 기능·출처 범위

**성격:** HUFS One AI(독립 프로젝트)가 기존 HUFSAbility의 학생 정보 탐색/기능 구조를 **정직하게 설명하기 위한 공개 출처 참고 원장**. 학교의 최신 운영 변경을 실시간 확인하거나 공식 HUFSAbility 내부 데이터/API/SSO를 이용했다는 뜻이 아님. 기존 학교 UI/코드/학생 데이터의 무단 복제·원문 재배포 금지.

## 확인 자료와 신뢰도

| 증거 구분 | 설명 |
| --- | --- |
| 공식 공개 페이지·메뉴 | 한국외대 소유 `hufs.ac.kr` 도메인의 공개 안내/비교과·채용·대외활동 메뉴. 페이지 접근 가능 여부·이용 조건·내용 변경은 개별 시점 재검증 필요 |
| 학교 발행 사용자 매뉴얼 | 학생 메뉴 5분류·24개 기능의 **문서화된 정보구조**. 모든 메뉴가 현재 웹에서 동일하게 제공/운영된다는 뜻은 아님 |
| 승인된 개인 학생 계정의 UI 조사 | 별도 관찰된 11영역/76화면 구조. 현재 화면/실제 서버 동작·저장/지원 성공·공식 SSO 권한까지 확인한 수가 아님 |
| 시연 데이터 | 개인/기관 원본과 독립한 5개 가상 학생 슬롯/40공고/10공지와 원본 기반이 아닌 창작 자산 |

## 현재 주요 메뉴 범위

공개 5분류 **역량관리 4·교과/비교과 5·채용 6·경력개발 4·통합상담 5**(24기능)와 비로그인 **교내비교과·장학공지·공지사항·채용정보**(4영역). 학생 계정에서 관찰된 11영역/76화면은 별도 범위. 이 둘을 같은 집합으로 세거나 기능 미제공이라고 주장하지 않는다.

HUFS One AI 자체는 상단 8개 주요 메뉴·모바일 5탭, 홈 근거/개인 요약, 맞춤 기회/공지/달력/학업/경험·가상 동아리를 제공하지만 원본 24기능은 **미지원으로 표시**, 공개 4영역은 학교 공식 첫 페이지로 연결한다.
