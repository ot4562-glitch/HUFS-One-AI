# HUFS One AI | 자료·동의·게시 경계

기준: 2026-10-29 최신 사용자 지시와 [Proposal.md](../../Proposal.md) §8.2·§11.3·§13~15. 이 문서는 법률 판단이나 학교의 이용 허가를 대신하지 않는다.

## 유지할 사실과 변경된 계획

학교가 데이터 협조·SSO·공식 운영을 승인했다는 확인은 없다. 과거의 '학교가 데이터 협조를 약속했다'는 전제는 2026-10-28 사용자 정정으로 무효다. 이번 디자인·실제 5명 시연 계획 변경이 기관 승인을 뜻하지 않는다.

**현재 주시연 계획은 실제 5명 + 실제 한국외대 졸업요건**으로 변경됐다. 이전 합성 전용 주시연 방침을 현재 기준으로 사용하지 않는다. 다만 아직 다섯 명의 동의·원장·전공 조합을 수령·검증하지 않았으며 수치를 미리 확정하지 않는다. 공개 개발용 합성 회귀시험과 실제 자료의 제한 검증은 별개다.

`SYNTHETIC`, `PERSONAL_CONSENTED_LOCAL`, `LICENSED_EXTERNAL`, `RESEARCH_REFERENCE_ONLY`와 목적별 처리/저장/전송 승인 정보를 함께 확인한다. 인터넷에서 읽을 수 있다는 사실, 당사자의 학업기록 제공, 클라우드 저장 동의, 공개 게시 동의는 서로 대체하지 않는다. 원본 인터넷 공개가 재배포 허가를 뜻하지 않는다.

## 담당 역할

학사자료 에이전트가 출처·버전·적용범위를 정리하고, 독립 검토 에이전트가 실제 원장과 규칙을 대조한다. 개인정보·게시 검증 에이전트는 수집 필드·동의·제외 경로·철회를 확인한다. 목적·위험·대안은 **사람이 에이전트와 함께** 결정하되 개인 동의·기관 허가·결제/공개 승인은 권한자가 한다.

실학생 자료·동의·대응표·개인 기대값/replay는 `local_only/real5/`에 보관한다. 공개 저장소는 자체 문서·도구·향후 코드·허용된 합성 사례로 구성한다. 이미 추적된 민감자료가 발견되면 게시를 중단하고 복구를 공동 결정한다. 현재 새 GitHub 원격·업로드·유료 자원·제품 구현은 수행하지 않는다.
