# HUFS One AI — HUFSAbility·학생 자료 현재 이용 허가 경계

**현재 사용자 확인:** 공모전 참여자 **5명 전원 동의**와 HUFSAbility **자료 수집 허가 확보**. 실제 개인 수강 CSV/Forms 제공자는 **4명**. 공식 시간표의 공개 강의명·교수명은 허가된 수업정보 안내의 필요 범위로 다루며, 일괄 무조건 마스킹을 신규 필수 요건으로 놓지 않는다.

다만 수집 허가와 **학교 공식 HUFSAbility 운영/SSO/원본 화면 코드·디자인 이용권/기관별 문서 재배포·원본 외부 AI/NCP 전송·개인별 과거 Git 게시·현재 동의/철회**는 각각 다른 권리이다. 실제 목적·원본·필드/기간/재배포·AI 전송 허용 범위를 제한된 비공개 원장으로 확인하기 전에는 실원본의 공개/외부 호출을 금지한다.

## 자료별 처리

| 자료 | 기본 취급 |
| --- | --- |
| S01–S05/EMPTY/REVIEWER 합성 | 합성 로컬 개발·CI 사용 허용, 실제 학생처럼 표시 금지 |
| HUFSAbility 공개 원문·학생안내 | 출처/관찰 범위·이용조건을 확인한 제품 제안·메뉴 참조. 실제 수집/저장/display/AI 외부전송 권리는 개별 허가 영수증으로 대조 |
| 공식 학칙·시간표 | 적용 학년도/학과/규정 조항/최신 시점·권리·RulePack 독립 승인 전 공식 졸업/개설 확정 금지 |
| 개인 CSV/Forms 4인 | current owner/consent·필드별 목적/보관/팀 공유·최초 Git 게시/clone/backup·NCP/AI 전송·철회 확인 전 private 미승인 경로 차단 |
| 인증/개인 신원 대응 | 제한된 vault/private 기록만, Git/PR/CI/issue/public build/외부 모델로 원문/SID·토큰 반입 금지 |

현재 Git 추적 보호 경로 0과 과거 접근 가능한 보호 이력 6경로/전체 private checkout의 기존 2 FAIL 감사는 **다른 증거**이고, 역사적 접근/clone·fork/backup·철회가 실제로 안전하다는 수락이 아니다. 승인 없는 이력 강제 재작성/원문 공개 금지.
