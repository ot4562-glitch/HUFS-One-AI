# HUFS One AI — HUFSAbility·학생 자료 현재 이용 허가 경계

**현재 사용자 확인:** 공모전 참여자 **5명 전원 동의**와 HUFSAbility **자료 수집 허가 확보**가 보고됐으며, 이어 사용자가 문서상 개인정보·기관 자료·수집·저장·공유/게시·NCP·AI 전송 및 운영에 필요한 프로젝트 승인을 모두 받았다고 확인했습니다(**OWNER_CONFIRMED_APPROVED**). 실제 개인 수강 CSV/Forms 제공자는 **4명**. 공식 시간표의 공개 강의명·교수명은 허가된 수업정보 안내의 필요 범위로 다루며, 일괄 무조건 마스킹을 신규 필수 요건으로 놓지 않는다.

다만 수집 허가와 **학교 공식 HUFSAbility 운영/SSO/원본 화면 코드·디자인 이용권/기관별 문서 재배포·원본 외부 AI/NCP 전송·개인별 과거 Git 게시·현재 동의/철회**는 각각 다른 권리이다. 프로젝트 전체 승인 미획득을 이유로 승인된 실원본 처리 기능을 일괄 차단하지 않는다. 다만 실제 자료의 출처·버전, 해당 학생의 현재 동의/삭제/철회, 목적/필드/기간/재배포·AI 전송 범위를 비공개 원장과 대조하지 못한 요청은 거부한다. 현재 외부기관 계약서/실사용자별 영수증·운영 연결이 독립적으로 검증됐다고 표시하지 않는다.
