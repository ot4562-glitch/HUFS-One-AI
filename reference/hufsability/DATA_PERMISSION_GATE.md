2026-10-29 당시에는 학교의 데이터 협조·SSO·공식 운영 승인을 확인하지 못했다. 2026-11-04 사용자 확인으로 **HUFSAbility 자료 수집 허가는 확보**되었으며, SSO·공식 운영 승인과는 구분한다. 과거의 '학교가 데이터 협조를 약속했다'는 전제는 2026-10-28 사용자 정정으로 무효다. 이번 디자인·실제 5명 시연 계획 변경이 기관 승인을 뜻하지 않는다.

**현재 주시연 계획은 실제 5명 + 실제 한국외대 졸업요건**으로 변경됐다. 이전 합성 전용 주시연 방침을 현재 기준으로 사용하지 않는다. 2026-10-29 당시 다섯 명의 동의·원장·전공 조합 검증은 진행 중이었다. 2026-11-04에는 **5명 동의가 확인**되었으며, 실제 학업 원본 제출 범위(4명) 및 공식 RulePack 수락은 별도이다. 공개 개발용 합성 회귀시험과 실제 자료의 제한 검증은 별개다.

## 담당 역할

학사자료 에이전트가 출처·버전·적용범위를 정리하고, 독립 검토 에이전트가 실제 원장과 규칙을 대조한다. 개인정보·게시 검증 에이전트는 수집 필드·동의·제외 경로·철회를 확인한다. 목적·위험·대안은 **사람이 에이전트와 함께** 결정하되 개인 동의·기관 허가·결제/공개 승인은 권한자가 한다.

실학생 자료·동의·대응표·개인 기대값/replay는 `local_only/real5/`에 보관한다. 공개 저장소는 자체 문서·도구·향후 코드·허용된 합성 사례로 구성한다. 이미 추적된 민감자료가 발견되면 게시를 중단하고 복구를 공동 결정한다. 이 문장은 2026-10-29의 작업 범위 기록이다. 최신 GitHub/배포 상태는 STATUS를 확인하고 사용자 사전 승인 없는 유료 자원·운영 공개는 수행하지 않는다.
