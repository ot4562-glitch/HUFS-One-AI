# HUFSAbility 2023~2026 고도화 증거 조사 (2026-10-28)

**기관: 한국외국어대학교 단독.** 외부대학/비공식 복제 콘텐츠는 증거에서 제외했다. PDF 로컬 원본은 reference/hufsability/raw 안에 내부 조사용으로만 보존하며 배포·공개 GitHub 복제 금지. 각 PDF 출처 URL·SHA-256은 EVOLUTION_SOURCES.json에서 추적.

**결론:** 한국외대는 HUFSAbility를 방치하지 않았다. 학교가 2020년 도입 이후 매년 고도화했다고 명시했고, 전공설계 상담·모바일/검색·개인 맞춤 추천 계획·인증제도 개편까지 추진했다. 따라서 '학교가 아무것도 안 한다'가 아니라 **지속 개선 중인 기존 서비스에서 학생의 구체 교외기술·이중전공 정보와 신청 가능 조건/역할별 행동 연결을 한 단계 더 검증·고도화한다**고 제안한다. 실제 2026년 로그인 기반 추천 품질은 미검증이며 이를 이미 없다고 단정하면 안 된다.

## 2. 예선에 쓸 수 있는 주장과 쓰면 안 되는 주장

**사용할 논지:** 한국외대의 지속적인 HUFSAbility 투자는 고도화 요구의 **제도적 중요성**을 입증한다. 학생이 직접 겪는 문제는 기존 기능의 존재와 구분해 **정보 발견 → 실제 지원 자격 확인 → 필요한 서류/팀 역할/마감 → 학생의 다음 행동**을 일관되게 연결할 수 있느냐는 검증 과제로 제시한다. 기존 전공설계 상담과 키워드 구독·취업 추천이 있다는 사실은 인정한다.

**차별화 가설:** 학생이 자발적으로 공개한 방학 중 **Linux 서버 운영·GitHub 오픈소스 기여·AI 프로젝트**, 실제 **이중전공/이수과목**을 구체 SkillTag로 정리하고 학교 비교과·외부 채용/공모전 원문의 추가조건·절차까지 연결해 학생의 시간·오판을 줄인다. CLOVA Studio로 비정형 원문/활동 텍스트 해석, TypeScript 결정론 엔진으로 자격·마감 판정 및 UNKNOWN 처리, NCP DB/Server에서 출처·검증 기록 보관. 이 연결이 HUFSAbility에 부재함을 공식 자료가 증명한 것은 아니다.

**피할 표현:** 'HUFSAbility는 모바일에서 접근할 수 없다', '통합검색이 없다', '외부활동 등록이 없다', '진로추천/개인 맞춤 기능이 없다', '학교는 의견을 듣지 않는다', '83.25% 학생이 불만이다', '새 AI추천 서비스를 처음 만든다'. 2025 계획이 실제 2026 출시됐는지는 로그인 실사용으로 재검증.

**실증 계획(미완료):** 동의한 학생 5명×3과제의 실제 공고 발견시간·클릭·지원자격 정답/오답, 소량 공고 메타데이터와 원문 조건 대조, 기존 키워드 구독/추천과 외부활동 실적의 연결 정도 조사. 지금까지 수집한 공개 목록 30건은 상세 본문 불일치율·추천 오류율을 증명하지 못한다.

## 3. 권장 예선 제안서 문단(아직 개인 후보)

한국외국어대학교는 HUFSAbility를 2020년 구축 이후 지속 고도화하고, 2024년 전공설계 상담 기능을 확장했으며, 2025~2027 사업성과지표에도 HUFSAbility 개발실적을 명시하고 있다. 2025년에는 AI 기반 개인 맞춤형 피드백·프로그램 추천 고도화를 계획했고, 2026년에는 역량인증 기준과 오픈배지 활용을 개편했다. **본 제안은 기존 시스템의 실패나 기능 부재를 주장하지 않고**, 학생이 허용한 두 전공·이수과목·방학 프로젝트가 지금 지원 가능한 교내외 기회, 공고 본문의 실제 자격조건, 개인별 신청 단계에 연결되는 과정을 검증하고 자동화하는 **다음 단계의 학생 중심 고도화**를 제안한다. 학생의 실제 탐색 시간 절감과 조건 판정 오류 감소는 예선 이후 측정할 가설이며, 이미 확인된 성과가 아니다.
