## 3. 개설 전망: 간단한 검증 결과

방법: "직전 같은 학기에 열렸으면 이번에도 열린다" (Architecture.md A09.4의 비교 기준 `직전동일학기반복`과 같음). 2025년 자료로 2026년 두 학기를 예측.

| 지표 | 결과 |
|---|---|
| 열린다고 예측한 것 중 실제 개설 | 34/38 = 89.5% |
| 실제 개설된 것 중 미리 맞힌 것 | 34/38 = 89.5% |
| 전체 (예측 또는 실제 개설 42건) | 34/42 = **81.0%**, 틀린 것 8건 |

틀린 8건 (6과목):
- 경제사·경제발전론: 봄↔가을 학기 이동 (각 2건)
- 수리경제학: 2023·2025 봄만 개설, 격년으로 보여 2026-1 미개설
- 실험행동경제학: 2023~2025 가을 연속 개설 후 2026-2 미개설
- 경제성장론: 가을 과목인데 2025-2만 쉬었다가 2026-2 다시 개설
- 경제이슈분석: 2023-2 이후 3년 만에 2026-2 다시 개설

"직전 같은 학기" 하나만 보는 방식은 격년·한 번 쉰 과목에 약합니다. 같은 학기 4번 이력을 함께 보면 일부는 줄일 수 있습니다.

주의: 예측 시점이 한 번(2025년 자료 → 2026년)뿐인 한 학과 결과라, A09.4가 요구하는 rolling-origin 검증으로 보기 어렵습니다. 일반적인 정확도로 소개하지 않고, 화면에는 A09.2대로 "과거 같은 학기 n번 중 k번 개설"로 보여주는 게 맞습니다. 틀린 과목은 학기 이동·격년·재개설처럼 들쭉날쭉한 과목이라 "공고 확인 필요" 표시가 필요합니다.

Course Compass 판정 → A09.2 상태 대응 (안):

| Course Compass | A09.2 |
|---|---|
| 개설 가능성 높음 | HISTORICAL_PATTERN (k/n 높음) |
| 공고 확인 필요 | HISTORICAL_PATTERN + 확인 필요 |
| 드물게 | HISTORICAL_PATTERN (k/n 낮음) |
| 기록 없음 (4번 중 0번) | HISTORICAL_PATTERN (0/4) |
| (없음) | INSUFFICIENT_DATA (관측 3번 미만·과목코드 변경 미확인), CONFIRMED_OPEN/CLOSED, EVENT_REVIEW — 새로 필요 |

계절마다 관측이 4번(n=4)이라 A09.2의 "n≥3" 조건은 충족합니다.

## 4. 졸업요건 변환기: 실제 CLOVA 테스트 결과

경제학부 졸업요건 안내문을 HCX-007(Structured Outputs)로 규칙 JSON으로 변환하고, 서버가 숫자·과목명·근거 문장을 원문과 대조합니다. 적용은 사람 승인 후.

- 2026-10-30 실제 호출 3회. 첫 호출 기준 7.6초(7,553ms), 토큰 1,152개
- 원문 대조 검사 **10/10 통과** (학번별 학점, 전공필수 4과목, 졸업시험). 지어낸 값 없음
- **문제: 3회 모두 원문의 `※` 예외 문장을 빠뜨림**  
  (타학과에서 자유선택으로 들은 전공필수는 재수강, 이중전공자 포함, 부전공자 제외)
- 원인: 지시문에 예외 문장을 뽑으라는 규칙이 없음. 검사는 "지어낸 것"만 잡고 "빠뜨린 것"은 못 잡음
- 고칠 방향: 지시문에 예외 규칙 추가 + 원문에 `※`·`단`·`제외`가 있는데 예외가 비어 있으면 경고

이 변환기는 Architecture.md의 AI 작업 4종에는 없습니다. 학생 데이터를 쓰지 않는 **RulePack 초안 작성 도구**(공식 안내문 → 규칙 후보 → 사람 검수)로 쓰면 A08.3의 근거 연결(evidenceRefs) 요구와 맞습니다. 기획서의 AI 활용·NCP 근거로도 쓸 수 있습니다.
