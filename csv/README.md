# 실제 두 명의 수강과목 — 비공개 협업 입력

기존 두 CSV(48행, 39행)는 이수완료/현재수강의 과목 기록이다. 동일한 6열 **학기,학수번호,과목명,학점,이수구분,이수상태** 헤더를 확인했다. GitHub에는 UTF-8로 업로드한다(한 파일은 CP949에서 변환).

**파일명에 실제 표시이름이 포함된다.** 이 데이터는 합성 fixture가 아니며 개발 브랜치에 있더라도 다른 협업자가 열람할 수 있다. 팀원별 공유 동의/접근범위를 확인하고, 외부 AI·정적 빌드·CI·로그·클라우드 업로드에는 사용하지 않는다.

자세한 [데이터 정책](../docs/DATA_GOVERNANCE.md) 및 Architecture.md A03 참조. 새 학생 파일은 별도 승인된 변경으로 추가한다.
