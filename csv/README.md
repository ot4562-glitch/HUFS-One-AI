# 운영 자료 경계 — Private 저장소에 있는 입력 파일

**2026-10-31 파일 구조 점검:** Private `main`에는 수강과목 CSV 4개(61·39·48·28개 데이터 행, 동일한 6열 헤더)와 Forms 통합 CSV 1개(26열 헤더·응답 4개)가 존재한다. 모두 BOM 없는 UTF-8이며 인용·열수 검사에 성공했다. 기존 3개 과목 파일의 명시적 업로드 지시는 확인되지만, 추가 수강 파일과 Forms의 원본 게시·팀 전체 열람·외부 처리 동의/출처는 이 형식 검사로 확인되지 않는다. 원본 열·값·표시이름 대응은 다른 문서나 PR에 복제하지 않는다.

**파일명에 실제 표시이름이 포함된다.** 이 데이터는 합성 fixture가 아니며 개발 브랜치에 있더라도 다른 협업자가 열람할 수 있다. 팀원별 공유 동의/접근범위를 확인하고, 외부 AI·정적 빌드·CI·로그·클라우드 업로드에는 사용하지 않는다.

상세 [데이터 정책](../docs/DATA_GOVERNANCE.md)과 [아키텍처 A03](../Architecture.md)를 따른다. 현재 추적된 파일까지 포함해 접근·동의·이력 감사를 실시하고, 새 실제 학생파일의 배포/외부 처리는 개별 확인 전 금지한다.
