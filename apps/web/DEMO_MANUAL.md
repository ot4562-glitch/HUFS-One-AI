모든 화면은 **합성(가상) 자료**로만 동작합니다. 실제 학생 정보·실제 서버·로그인·외부 AI·NCP는 이 절차에서 쓰지 않습니다.

| 합성 일부러 넣은 실패 | S04를 고르면 "공유 허용이 변경되었습니다"(403) 화면 |

## 상태 표기
- **동작:** 합성 모드에서 실제로 눌러 볼 수 있음
- **MOCK:** 화면은 있으나 브라우저 안 가짜 연결이 응답함(실제 서버 아님)
- **NOT_RUN:** 코드는 있으나 이 시연에서 실행·검증하지 않음
- **🚫 시연 미지원:** HUFSAbility 원래 메뉴 중 이번에 구현하지 않음

## 1. 빈 시연 계정 (#132)
| 단계 | 하는 일 | 예상 결과 |
|---|---|---|
| 1 | 위쪽 **시연 대상 옆 '설정'** 클릭 (Tab 키로도 이동) | "시연 계정 설정" — 모든 칸이 비어 있고 "아직 아무것도 설정하지 않았어요" |
| 2 | 아무것도 넣지 않고 **저장** | 각 칸 아래 오류(예: "주전공을 입력해 주세요."), 저장 안 됨 |
| 3 | 주전공 `가상통계학과`, 취득 학점 `0`, 내 관심 분야 `데이터 분석`, 이중전공 `있음` → `가상경영학과` 입력 후 **저장** | "저장된 설정 · 주전공 가상통계학과 · 취득 0학점" (빈칸과 0은 다르게 취급) |
| 4 | 값을 바꾼 뒤 **취소** | 저장된 값으로 돌아옴 |
| 5 | **시연 계정 초기화** → 확인 창에서 **초기화** | 처음처럼 모든 칸이 빈 상태 |

- 학점은 **취득 학점**이며 성적(평점)·공식 이수 확인이 아닙니다. 0.5학점 단위, 0~250.
- 상태: 저장·취소·초기화 **MOCK**(브라우저 안 가짜 계정). **저장한 설정으로 추천·공지·동아리를 다시 계산하는 서버 연결은 NOT_RUN**(공통 계약·API 대기, 심민성). 화면에도 그렇게 적혀 있습니다.
