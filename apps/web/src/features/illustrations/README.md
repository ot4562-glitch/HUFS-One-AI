# 합성 포스터·기회 그림

`assets/manifest.json`은 8종 그림의 생성 도구·날짜·프롬프트·원본 SHA-256·alt·허용 용도와 480×270 / 960×540 WebP 16파일의 해시·용량을 기록한다. 신규 7종은 OpenAI 내장 이미지 생성 도구로 제작했고 기술 그림은 기존 `ai-club-poster-v1.png`를 재사용했다. 실제 모델 식별자는 도구가 반환하지 않아 `NOT_EXPOSED_BY_TOOL`로 명시한다. 원본 PNG는 수정하지 않았다.

`artwork.ts`의 명시적 ID 매핑은 승인/시점 게이트를 이미 통과한 합성 카드의 장식에만 사용한다. 공고의 자격·마감·추천 순위는 변경하지 않는다. 실제 공고·모르는 ID에는 합성 그림을 붙이지 않고, 모르는 동아리 poster ID와 이미지 로드 실패에는 기존 SVG가 남는다. 목록과 상세는 같은 매핑을 사용한다.

모든 그림에는 HTML의 “합성 예시 · 실제 모집 아님” 문구가 보이며 `picture`·명시적 크기·lazy loading·대체 텍스트를 사용한다. 글자·QR·연락처는 원본 이미지에 넣지 않았다. 그림의 장면은 실제 학교/동아리/기업의 증거나 모집 공고가 아니다. 별도 예시 갤러리의 동아리 6개·기회 6개는 유형/학년/캠퍼스/모집 상태를 설명하며 고정 40공고·10공지·추천 평가 입력에 추가되지 않는다.

`npm run assets:check`가 파일 목록·해시·형식·용량을 검사한다. `illustrations.test.tsx`는 합성 여부/ID 경계와 fallback을, `generated-artwork.spec.ts`는 320/360/390/768/1440px·실제 이미지 로드·상세 일치·손상 fallback을 확인한다. AI 시각 검토와 자동 브라우저 검증은 실제 사람의 포스터·기기/스크린리더 인수가 아니며, 그 인수는 #280에서 `NOT_RUN`으로 추적한다.
