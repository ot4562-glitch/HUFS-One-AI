# 웹 자산·포스터·합성 이미지와 출처 권리

**현행 협업:** 김채윤 `qamarrchae`([#358](https://github.com/ot4562-glitch/HUFS-One-AI/issues/358))이 실사용 포스터·공고 이미지/본문·출처 및 게시/모델 이용권·Gold·시연 자산을 정리한다. 이서연 `lhh42001`([#357](https://github.com/ot4562-glitch/HUFS-One-AI/issues/357))이 이 자료를 실제 웹 UI/UX·카드·배너·상세 디자인에 활용한다. 심민성 `ot4562-glitch`([#359](https://github.com/ot4562-glitch/HUFS-One-AI/issues/359))이 자료/디자인·보안·릴리스 계약을 전 과정 검수한다. 신규 기능은 최초 심민성 구조 설계 후 박준영/이의상이 구현하고 필요한 자산을 인수한다. [루트 AGENTS](../AGENTS.md).

학교 로고·공식 UI/캐릭터·교수/학생 사진·상표·원문 자료는 출처별 권리 범위를 확인한다. 포스터는 실제 모집/공식 자료와 `SYNTHETIC_DEMO` 예시를 구조적으로 구분한다. 공개/비공개·이미지 복제·OCR·LLM 전송·게시·수정/철회 범위를 자료별로 기록한다.

가상 자산의 창작 경로/생성 도구·모델/프롬프트 버전·SHA·라이선스·허용 용도, 표시 비율·용량·alt·CSS 장식 여부를 확인한다. 실제 사생활/민감 자료와 비밀이 웹 번들·Pages·ZIP에 포함됐는지 점검한다.
