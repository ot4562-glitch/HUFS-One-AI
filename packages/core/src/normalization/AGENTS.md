# 공고·관심·Topic 정규화

**현행 역할:** 김채윤([데이터 #358](https://github.com/ot4562-glitch/HUFS-One-AI/issues/358))이 공식 공고·출처/권리·토픽 교차표·독립 Gold 자료를 공급한다. 심민성([총괄 #359](https://github.com/ot4562-glitch/HUFS-One-AI/issues/359))이 신규 추가기능 구조·계약을 먼저 설계하고, 이후 이의상/박준영 중 기능 구현 주담당이 관련 정규화 코드를 구현한다. 두 AI 개발자는 코드/HCX-007/OCR 결과를 서로 검토하고 박준영이 AI 제품 기술 QA를 수행한다. 이서연은 UI 소비를 연결한다. [루트 AGENTS](../../../../AGENTS.md).

허가된 출처의 문장·토픽·alias와 닫힌 TopicCode 24종, 원문 문단 SHA/개정·학기/캠퍼스 차이를 유지한다. 사용자 관심·지원 조건·관련도는 근거에 연결하며, 소스와 동의가 미확인된 경우 검토 필요 상태로 남긴다. 공통 계약/API 변경은 구조 설계·소비자 교차 리뷰를 거친다.
