# 개설·학사 사건 전망

**박준영 학업/전망 코어 소유**. 공식 학기/강의시간표의 확정 개설과 과거 패턴/가정·누락/UNKNOWN·0/n를 분리. SourceRevision/asOf/rolling-origin·campus/cohort/RulePack 권한에 따라 보수적 판정하며 개인 예측을 실제 미개설/확정이라고 표시하지 않음. 실제 학교 자료의 이용권·8학기/20과목 목표 검증·독립 평가 전 공식 예측 성공 주장 금지.

**평가(`rolling-origin.ts`):** 과거 시점마다 그때 공개·확인된 자료만으로 전망과 기준선 3개(최근 같은 계절, 과거 다수, 항상 개설)를 같은 항목에서 채점한다. 목표 학기가 이미 공개됐거나 정답 목록이 없거나 엇갈리면 모든 방법에서 함께 뺀다. 개수만 내고 확률·비율·IoU는 내지 않는다. 실제 학교 자료로 돌린 결과는 이용권 확인 전까지 Git·PR·CI에 올리지 않는다.
