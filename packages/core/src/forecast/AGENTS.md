SourceRevision/asOf/rolling-origin·campus/cohort/RulePack 권한에 따라 보수적 판정하며 개인 예측을 실제 미개설/확정이라고 표시하지 않음. 실제 학교 자료의 이용권·8학기/20과목 목표 검증·독립 평가 전 공식 예측 성공 주장 금지.

**평가(`rolling-origin.ts`):** 과거 시점마다 그때 공개·확인된 자료만으로 전망과 기준선 3개(최근 같은 계절, 과거 다수, 항상 개설)를 같은 항목에서 채점한다. 목표 학기가 이미 공개됐거나 정답 목록이 없거나 엇갈리면 모든 방법에서 함께 뺀다. 개수만 내고 확률·비율·IoU는 내지 않는다. 실제 학교 자료로 돌린 결과는 이용권 확인 전까지 Git·PR·CI에 올리지 않는다.

**과거 범위(`offering.ts`, `forecast-offering-v3`):** 목표 학기 전 정규학기 8개(같은 계절 최대 4개)만 과거 횟수에 쓴다. 그보다 오래된 행은 빼고, 미개설로 세지 않는다. `NOTICE_ONLY`는 목표 학기 확정에는 쓰지만 k/n에는 세지 않는다.

**과목 확인(#11, `forecast-offering-v3`):** 관측 행마다 `courseIdentity`를 둘 수 있다. `EQUIVALENCE_UNVERIFIED`이거나 기준 시점 뒤에 확인된 행은 개설·미개설·n 어디에도 세지 않는다. 목표 학기에 미확인 행만 있으면 과거 횟수로 대신하지 않고 `INSUFFICIENT_DATA`다. 대상 과목 자체가 미확인이면 `UNKNOWN`이다. 칸이 없으면 호출 쪽이 이미 맞춘 행으로 보는 기존 뜻 그대로다. rolling-origin 정답도 같은 규칙을 쓴다.
