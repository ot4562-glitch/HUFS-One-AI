# 학생별 중요공지·행사 근거

**업무 협업:** 김채윤([데이터 #358](https://github.com/ot4562-glitch/HUFS-One-AI/issues/358))은 공식 공고·포스터·학과/학생회 행사·출처·게시권/정정 판본을 공급한다. 신규 `[추가 기능]`은 심민성의 구조 설계 후 [박준영 #356](https://github.com/ot4562-glitch/HUFS-One-AI/issues/356) 또는 [이의상 #355](https://github.com/ot4562-glitch/HUFS-One-AI/issues/355) 중 기능 주작성자가 코드로 구현한다. 이서연은 공지/일정·검색 UI를 배치하고, 박준영은 AI 정확도 기술 QA, 심민성은 코드·권한·통합을 전 과정 검수한다. [루트 AGENTS](../../../../AGENTS.md).

학과/학년·행사/모집 마감·정정/취소·확정/예상의 구분과 `SourceRevision/asOf/rights`·처리 근거를 유지한다. 학사·개인 자료가 불분명하면 `UNKNOWN`으로 안내하며 공식 자격/시점을 임의로 확정하지 않는다. 신규 기능 이슈의 주작성자와 웹/API 소비자는 동일 정본의 판본과 상태를 검증한다.
