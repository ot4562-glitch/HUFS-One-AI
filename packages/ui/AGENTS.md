# 공통 UI·접근성·웹 컴포넌트

**현행 구현:** 이서연 `lhh42001`([웹 역할 #357](https://github.com/ot4562-glitch/HUFS-One-AI/issues/357))이 공통 React 컴포넌트·UI/UX·포스터/자료 시각화와 기능 배치를 주도한다. 김채윤 `qamarrchae`([#358](https://github.com/ot4562-glitch/HUFS-One-AI/issues/358))이 실사용 콘텐츠·게시 가능한 이미지/문구를 공급하고 사용자 관점으로 시연·제보한다. 박준영은 AI 제품 기술 QA, 이의상은 AI 출력/문장 근거의 교차 검증, 심민성은 전체 디자인/코드 검수를 수행한다.

새 `[추가 기능]`은 심민성 최초 구조/계약 설계 후 박준영 또는 이의상을 본기능 개발 assignee로 지정하고, 이서연이 실제 웹 배치를 맡는다. [루트 AGENTS](../../AGENTS.md).

현재 디자인 토큰·포커스·터치 목표·데스크톱/모바일 메뉴·스크린리더·alt/상태·공식 아님 표기를 유지한다. 학교 로고/원본 HUFSAbility 코드·이미지는 출처별 이용권을 확인한다. 학점/학사 자격/추천의 실제 규칙 판정은 서버/코어 정본과 연동하며 UI에서 근거 있는 결과를 표시한다. API/계약 변경은 관련 기능 주작성자·총괄과 교차 검토한다.
